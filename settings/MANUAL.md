# データを作成する際の書き方

## 生成するデータの設定方法
- GenerateList
    - 生成したいデータの情報を配列として記述
    - 一番上に書いた設定から読み込まれる

## 構造体の設定方法
- Nは好きな名前でもよい
- N1 は生成される構造体の名前
``` yaml
(N = 任意の文字列)_struct: (N1 = 名前)
(N = 任意の文字列)_struct_member:
    -
        - (メンバの名前)
        - (メンバの型)
    - ...
```

## 列挙型の設定方法
- 命名規則は構造体と同じ
``` yaml
(任意の文字列)_enum: (名前)
(任意の文字列)_enum_member:
    - (メンバの名前)
    - ...
```
